# 草莓猫桌宠 0.6.0 · 相伴成长与回忆

本次更新加入渐进式陪伴成长。摸摸小猫、一起工作、一起休息，会慢慢留下熟悉感和可以回看的日常。

## 新内容

- 四个关系阶段：初见、熟悉、亲近、默契。日常与工作都能自然积累熟悉度，离开不扣分，也不要求连续签到。
- 日常点击使用情境短句，按关系阶段提供不同回应。沿用现有骨骼动作，工作和休息计时照常使用。
- 12 条永久回忆，每条配有专属草莓猫插画；已记录的回忆会直接显示对应图片。
- 新增“我们的日常”面板，可从右键菜单、托盘和设置进入，查看相伴天数、关系阶段与回忆。
- 成长记录和陪伴文字可分别关闭；成长存档独立保存，并提供备份、读取恢复和保存重试。

## 下载与更新

推荐下载 [Windows x64 安装包](https://github.com/Catalyst259/TablePet/releases/download/v0.6.0-skeletal/TablePet.Skeletal-0.6.0-Setup.exe)。也可选择 [ZIP 便携包](https://github.com/Catalyst259/TablePet/releases/download/v0.6.0-skeletal/TablePet.Skeletal-0.6.0-win-x64.zip)。两者包含 .NET 运行时、全部骨骼素材和回忆插画，无需开发环境。

已有骨骼版用户可运行安装包并选择原安装目录更新，保留设置和相伴记录。首次从 0.5.0 更新时，成长从实际使用开始记录，不补算历史时长；本地预览版已有的记录可以继续使用。

安装默认按当前用户进行，不需要管理员权限。原逐帧版与骨骼版使用独立安装目录和身份。完整说明见 [安装与卸载](INSTALLATION.md)。

源码继续在 `skeleton` 分支维护；`legacy` 和旧发布用于历史归档。
