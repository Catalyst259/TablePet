# 0.4.0 · 日常陪伴与工作模式

2026-11-09 正式发布。下载 [0.4.0 Release](https://github.com/Catalyst259/TablePet/releases/tag/v0.4.0)：[Windows x64 安装包](https://github.com/Catalyst259/TablePet/releases/download/v0.4.0/TablePet-0.4.0-Setup.exe) 或 [免安装 ZIP](https://github.com/Catalyst259/TablePet/releases/download/v0.4.0/TablePet-0.4.0-win-x64.zip)。两者均内置 .NET 运行时和最终素材，无需安装开发工具。

## 使用

默认日常陪伴，保留现有随机待机、点击回应和无交互入睡。设置、猫咪右键菜单、托盘均可选择工作模式；工作／休息默认 25／5 分钟，在设置中修改，支持小数分钟。模式和时长自动保存，旧配置缺少新字段时仍为日常模式。重启工作模式会开始新一轮，剩余时间不跨重启保存。

| 时机 | 表现 |
| --- | --- |
| 开始工作 | 当前动作收尾，必要时唤醒；喵叫＋“开始工作啦~”，然后电脑与 Working 小标淡入。 |
| 工作中点击 | 保持专注动作，只提示“工作呢，别打扰我”。 |
| 工作到点 | 退出工作场景，Wink＋“休息一下吧~”，随后入睡。 |
| 休息中点击 | 唤醒、哈欠＋“和我一起休息”，再继续睡。 |
| 休息到点 | 唤醒，开始下一轮。 |

工作计时从 `work_loop` 开始，休息计时从本轮首次 `sleep_loop` 开始；进入、退出和首轮入睡过渡不占对应时长。休息中的点击不会重置计时，回应动画仍计入本轮休息；回应结束时若已到点，直接开始下一轮。悬停不会打断工作或休息。

拖拽、隐藏、系统挂起及“暂停工作／休息计时”同时冻结动作、气泡与轮次计时，恢复后继续。切回日常会平滑收尾。日常的“暂停自动动作”仍允许点击互动，与工作模式的冻结语义不同。

## 素材和配置

工作保留趴姿、专注下视眼神、最大 2 像素的整猫起伏；眨眼时身体继续起伏，电脑与标牌固定。进出各 400ms，退出时先完成正在进行的眨眼。工作循环为 9.6 秒，起伏每轮 4.8 秒。

当前清单为 **16 个 clips**，包含新增的 `work_enter`、`work_loop`、`work_exit`、`work_props`，另有萤火虫装饰轨道。原日常素材及已选定哈欠 v2 保留。制作来源与核验命令见 [工作场景设计](COMPANIONSHIP-INTERACTION-DESIGN.md)。

同日动画计时修复：保留全部 60fps 素材，入睡仍为 105 帧／1.75 秒，醒来仍为 63 帧／1.05 秒。播放器对符合采样声明的时间线还原均匀的分数毫秒边界，并使用 WPF 呈现时间推进动画，消除整数时间量化及 UI 回调早晚造成的重复、跳帧；回调之外使用高精度时钟衔接，入睡中断倒播同步修正。工作、休息及交互期限仍按真实时间计算。未增加图片或改变动作时长。

后续全动作复查补齐了动态中断回程、截止时间触发的新动作首帧，以及睡眠 Z 的呈现时间。常规素材、全部首尾衔接和有意停留保持不变。新增审计及最终交付记录见 `reference/motion-timing-fix/all-actions-verification.json`。

新增 JSON 字段：`mode`（默认 `"daily"`）、`workDurationMs`（默认 `1500000`）、`breakDurationMs`（默认 `300000`）。两项时长允许 1ms 至 8 小时，继续使用配置版本 1。完整字段与保存行为见 [配置说明](SETTINGS.md)。素材不完整时工作控制器回退到日常，右键与托盘工作入口禁用。
