# 0.3.0-preview.1 待机表情验收版

> 这是上一版的历史记录。当前本地版本为 [0.3.0-preview.2](UPDATE-0.3.0-PREVIEW-2.md)，已根据反馈重做笑眼、单眼眨眼，并将哈欠减速。

这是仅供本地验收的版本。尚未提交 Git、推送 GitHub 或发布 Release；公开安装版仍是 0.2.2。

## 这次增加什么

- 待机动作池包含原有眨眼，以及打哈欠、眯眼笑、轻眨单眼。
- 每次待机动作到期时随机选取；眨眼的相对权重较高，并避免连续播放同一个动作。
- 动作之间保留原有待机间隔，默认 3–8 秒。设置中的文字改为“待机动作间隔”，原有配置自动沿用。
- 悬停仍只影响睡眠/互动计时，不会自动起身。长表情过程中点击，先从当前可见姿态平滑收回，再接起身；眨眼仍先播完。
- 睡眠呼吸、入睡、唤醒、起身与蹲下沿用已有素材。

## 如何验收

先打开 `assets/strawberry-cat/previews/idle-actions-preview.html`。页面直接读取实际交付 PNG，可点播每个动作、切换深浅背景、暂停和拖动进度、选择正常速度或慢放，也能连续观察随机待机。无需启动服务器。

`idle-actions.gif` 是四动作并排的 50 fps 快速预览。应用素材时间轴仍是 240 Hz，实际显示帧率由屏幕和 WPF 合成器决定。

便携验收目录中的 `Start-Preview.cmd` 会请求当前桌宠正常退出，再运行该目录内的新版，不覆盖原安装目录。它沿用个人设置；关闭验收版后，可通过原桌面快捷方式重新运行已安装的 0.2.2。先前暂停了自动动作时，请从托盘菜单恢复。

建议观察：正常速度下张嘴/收口是否柔和、笑眼/单眼眨眼是否自然、回到趴坐是否跳变、连续随机时是否会重复同一动作。再试动作中点击，以及睡眠时悬停唤醒。

## 素材来源与重建

本版表情由内置 `image_gen` 生成；原图和所有候选保存在 `assets/strawberry-cat/sources/idle-v5`，完整提示词与选择记录见 `reference/idle-v5-prompts.json`。使用 Sharp 注册和合成生成的脸部，保留已经确认的身体、爪、尾巴与头饰；使用现成 RIFE 4.6 补帧，不引入新的动画渲染引擎。

```powershell
npm ci
npm run assets:idle
npm run assets:idle:check
npm run assets:idle:preview
```

补帧需要已配置的 RIFE 与 FFmpeg，详见 `tools/motion-pipeline.md`。普通构建和运行只读取已保存的 PNG，不需要这些素材制作工具或生图服务。

## 验证记录

本轮 102 项单元测试、40 项独立素材检查、19 项本地浏览器检查全部通过。真实 WPF 运行素材检查覆盖 11 个片段、1738 张 PNG、100 轮状态循环和 50,705 项断言；源码与便携目录素材的 SHA-256 逐项一致。独立 `--check-assets` 在无有效 `DOTNET_ROOT`、受限 PATH 下退出码 0，无素材回退。

| 动作 | 时长 | 时间槽 | 使用 PNG（含公共待机帧） |
| --- | ---: | ---: | ---: |
| 打哈欠 | 2200 ms | 528 | 276 |
| 眯眼笑 | 1300 ms | 312 | 130 |
| 轻眨单眼 | 900 ms | 216 | 119 |

三个新动作新增 522 张 PNG、1056 个时间槽。原有 1216 张 PNG 和 8 个动作片段与 `v0.2.2` 完全一致。首尾精确返回原待机帧；面部范围外 RGBA 保持原图，眼睛、嘴型、耳根和鼻梁在 512px 放大图与 240px 正常尺寸下复核。修正过旧虹膜残片、局部耳线、鼻梁贴片边缘及端点灰阶误差。哈欠张嘴期间保持闭眼。

固定随机种子的运行验证实际选中眨眼 605 次、哈欠 295 次、眯眼笑 286 次、轻眨单眼 287 次，没有连续重复同一动作。每种动作均覆盖点击、悬停、拖动、自动暂停、系统暂停和入睡期限。

报告位于 `artifacts/idle-v5-qa` 和 `artifacts/idle-v5-runtime`；构建记录位于 `artifacts/idle-v5/build-report.json`。性能采样记录来自最后一轮静态像素修正之前，已单独标明范围；不能用它证明屏幕/DWM 的实际呈现帧率。最终运行检查没有操控用户桌面；桌面观感留给此次验收，多屏等已有环境限制仍见 `docs/ACCEPTANCE.md`。
