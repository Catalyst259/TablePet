# 0.3.2 · 120Hz 素材冻结版

2026 年 10 月 30 日，用户在实际桌面体验 120Hz 测试版后确认“基本没有问题”，据此冻结本版。动画从此前确认的 240Hz 清单中取样，保留原画质、动作总时长和首尾姿态。本版同时包含已确认的连贯小幅双击喵叫与睡眠 Z 动画。

本记录对应源码冻结，Git 标签为 `v0.3.2`。公开安装包仍可从 [0.3.1 Release](https://github.com/Catalyst259/TablePet/releases/tag/v0.3.1) 获取；本次冻结不表示已发布 0.3.2 GitHub Release 或安装器。

## 取样规则与行为

活动片段按 `round(n × 1000 / 120)` 生成整数毫秒边界，在原时间线对应时刻选取 PNG，帧时长使用相邻边界之差。最后一个时间槽使用原动画末帧，确保片段连接与循环首尾保持原姿态。总时长不变；末帧可比原时间线提前几毫秒进入。

原 512×512、8-bit RGBA PNG 不缩放、不重编码，选中的文件保留原字节。连续使用同一 PNG 的时间槽不合并，避免改变点击打断、回程路线和倒播的既有计时规则。静态待机与保持仍各为一帧，不引入持续高频绘制。

自动待机池仍为眨眼和打哈欠，权重 4:1。单击仍等概率选择起身或 Wink；双击播放 1.4 秒的连贯小幅喵叫和气泡。睡眠 Z 与呼吸共用时间，拖动暂停、唤醒衔接、单/双击互斥、冷却和输入不排队规则沿用当前程序。

120Hz 指素材时间线密度。实际呈现跟随 WPF 合成器和显示器刷新，不保证每台电脑都以 120FPS 显示。

## 冻结与复现

- 原 240Hz 清单：`reference/motion-120hz/source-manifest-240hz.json`。
- 当前运行清单：`assets/strawberry-cat/manifest.json`。
- 确定性重采样工具：`tools/resample-motion-120hz.cjs`。
- 冻结指纹：`reference/releases/frozen-0.3.2.json`。
- 动作预览：`assets/strawberry-cat/previews/actions-preview-0.3.2.html`。

```powershell
# 从保存的源清单重建当前 120Hz 清单，不重新生成或编码 PNG
npm run assets:120hz

# 只读检查重采样结果和冻结素材指纹
npm run assets:120hz:check
npm run assets:freeze:check

# 构建、测试并生成含 .NET 运行时的本地便携 ZIP
powershell -NoProfile -ExecutionPolicy Bypass -File tools/build.ps1 -Test -Publish
```

原 Wink、Meow 等制作配方继续保留 240Hz 的完整姿态生成步骤。要修改动画，先制作并审阅新的源动画，再更新采样源、运行 120Hz 取样并重新验收。直接运行历史素材生成器会替换当前清单，不能据此声称仍满足本版冻结指纹。

普通克隆、构建和运行使用已经保存的 PNG，不需要生图服务或离线插帧工具。重采样复现只需要 Node.js 和仓库内的源清单、PNG，不依赖本机测试目录或推理缓存。

## 验证范围

120Hz 测试版已经逐动作验证名称、总时长、循环标志、首尾路径、静态单帧和逐槽取样规则；1275 张 PNG 与原版逐文件 SHA-256 一致，测试目录没有遗漏或多余动画帧。测试版 `TablePet.exe --check-assets` 在隔离外部 .NET 路径后退出码为 0，实际解码没有素材回退；启动后由用户确认观感。

当前源码执行 `tools/build.ps1 -Test`，构建零警告、零错误；187 项测试全部通过（Core 136、App 51），包含新增的 120Hz 时间边界参数检查。重采样复现和冻结指纹检查均通过。

0.3.2 自包含发布目录通过 `tools/verify-runtime.ps1 -ProbeAppHost -Cycles 1000 -ExpectedIdleActions blink,yawn`：程序在隔离外部 .NET 路径后完成全部素材解码，退出码为 0；1275 张 PNG、11 个片段、1000 次加速行为循环共 50318 项断言通过。循环覆盖入睡、呼吸、唤醒、起身/保持/蹲下、拖动与冷却，以及眨眼/哈欠的点击、悬停、暂停和挂起。检查固定起身分支，Wink 与 Meow 的行为由单元测试覆盖；全部动作 PNG 均已实际解码。

本轮修正验证脚本中独立点击选择与待机随机票混用的问题，使要求起身的测试明确选择起身，不修改应用行为。不同尺寸及 DPI 参数验证的是位图解码，不代表真实跨屏测试；加速循环不代表长时间驻留。安装器和真实升级未在本轮执行。检查摘要见 `reference/releases/verification-0.3.2.json`。

多屏混合 DPI、另一台干净 Windows 电脑、实际显示帧率和长时间运行仍按 [验收记录](ACCEPTANCE.md) 的相应范围处理。
