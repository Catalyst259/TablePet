# 草莓猫工作场景动画设计

2026-11-09，已接入本地 0.4.0。工作动画保留已确认的原猫趴坐姿势，电脑正对猫并遮住前爪；眨眼与整只猫的缓慢小幅起伏同时进行。此前的坐高、交替抬爪和眨眼时暂停身体的方案不再采用。已发布 GitHub Release 仍为 0.3.4。

**模式与一轮流程**

默认日常陪伴，可从设置、猫咪右键菜单或托盘切换工作模式。设置中的工作／休息时长默认为 25／5 分钟，可输入小数。旧配置缺少新字段时仍使用日常；模式和时长自动保存，重启工作模式从新一轮开始，不恢复上次剩余时间。

| 时机 | 动作与气泡 |
| --- | --- |
| 开始工作／下一轮开始 | 当前动作收尾，必要时先唤醒；喵叫并显示“开始工作啦~”，再进入电脑场景。 |
| 工作中点击 | 保持工作动作，仅显示“工作呢，别打扰我”。 |
| 工作到点 | 平滑退出电脑场景，Wink 并显示“休息一下吧~”，随后入睡。 |
| 休息中点击 | 唤醒、打哈欠并显示“和我一起休息”，之后继续睡。 |
| 休息到点 | 唤醒，开始下一轮工作。 |

工作从进入 `work_loop` 开始计时，休息从本轮首次进入 `sleep_loop` 开始计时。休息中点击不会重置期限，唤醒和哈欠的时间继续计入休息；若回应结束时已到点，直接进入下一轮。悬停不打断工作或休息。工作期间不安排日常随机动作和无交互入睡。

拖动、隐藏、系统挂起和“暂停工作／休息计时”会同时冻结动画、气泡与轮次计时，恢复后继续。切回日常时平滑收尾；日常模式既有点击、待机与睡眠规则保留。

**画面**

猫保留现有 idle 的原趴姿，头、身体、尾巴和草莓装饰保持原比例与相对位置。工作时有专属眼神：参考萤火虫掠过面前时的下视，双眼微微看向下方电脑，上眼睑轻轻收一点，保持清醒、柔和的专注感。电脑放在前景，屏幕朝向猫，背面对观众；遮住前爪，只看到猫在电脑后安静工作。Working 小标放在电脑旁。

电脑和标牌由 image_gen 生成，作为固定透明前景层，不跟随猫起伏。电脑位置保证整个起伏范围都遮住前爪，同时露出眼睛、鼻子和嘴。

**循环**

整张猫层一起轻微上下移动，512 像素画布上最大上移 2 像素、4.8 秒一轮。头、身体、尾巴和头饰共用同一个位移，不单独抬头低头，不缩放或挤压脸。运行时由 Core/WPF 计算整猫位移，道具保持独立固定层。

使用连续余弦曲线，只有自然转折，不人为停顿。工作眨眼保留 375ms 总时长，用专注睁眼与原闭眼素材制作眼部过渡；每次睁眼都恢复微微下视的工作眼神。眼睛闭合时，身体的起伏相位照常继续，不归零、不停止。

工作循环为 9.6 秒两轮起伏，眨眼分别在 1.25 秒和 6.7 秒开始。实际播放持续循环直到工作到点或用户退出工作模式。末帧按正常时间采样，虚拟循环终点与起点相同，不强塞重复尾帧。

**进入和退出**

进入工作时先完成原动作，必要时唤醒。回到原趴坐姿势后，用 400ms 将眼神平滑切到微微下视，电脑和 Working 小标同时淡入，然后从原位置开始工作循环。眼神使用待机与已确认工作睁眼之间的 33 个 RIFE 相位，退出时反向播放。

退出工作时，如果正处于一次眨眼，等这次 375ms 眨眼结束后立即开始退出；其他时刻立即开始。用 400ms 将眼神恢复待机、道具淡出，身体继续当前呼吸时钟并逐渐把起伏幅度收至零。无需等待整个 9.6 秒循环结束。位移、速度、加速度在退出两端连续，最终回到原待机像素。

开始工作使用现有 1.4 秒 meow；到点提醒使用 1.5 秒 Wink；休息点击使用已选定的 4.4 秒哈欠 v2。气泡与各自动作使用同一计时来源；工作点击提示持续 2.4 秒。气泡支持完整中文短句、随宠物缩放，并保持鼠标穿透、不抢焦点。

**制作与验收**

道具源图、提示词和布局在 `reference/work-v2`；专注眼神的生成记录在 `reference/work-v3`。已确认工作循环在 `assets/strawberry-cat/work-preview-v3`，进出过渡预览在 `assets/strawberry-cat/work-transition-v1`，前几版保留为比较档案。

运行素材位于 `assets/strawberry-cat/frames/work-v1`，由 `node tools/install-work-assets.cjs` 接入当前清单；`--verify` 只读核验，记录位于 `reference/work-runtime/verification.json`。只新增四个工作 clips，保留已有日常动作、哈欠选用和萤火虫轨道。

| Clip | 槽数 | 时长 | 内容 |
| --- | ---: | ---: | --- |
| `work_enter` | 24 | 400ms | 待机到专注眼神。 |
| `work_loop` | 576 | 9600ms | 专注猫与两次眨眼。 |
| `work_exit` | 24 | 400ms | 专注眼神回待机。 |
| `work_props` | 1 | 固定图层 | 电脑与 Working 小标，由运行时控制透明度。 |

验收重点是原姿势一致、视线微微向下且与待机有区别、眨眼后恢复专注眼神、前爪始终被遮挡、整只猫统一起伏、眨眼期间身体仍运动、电脑与标牌固定、循环接缝连续，以及浅深背景边缘干净。当前自动化与运行检查状态见 [0.4.0 版本说明](UPDATE-0.4.0.md)；该设计说明不代表已完成多屏、锁屏或长时间人工验收。
