# 0.2.1 微调记录

2026年10月27日，仅调整眨眼过渡和悬停/点击行为。

- 眨眼原关键姿态不变，使用现有RIFE工具补20张过渡PNG，减少开合眼的突变。总时长375ms、实际闭眼平台90ms。眨眼共25张独立PNG、92个时间槽。
- 悬停只打断入睡或唤醒睡眠，结束后保持趴坐；清醒悬停只更新互动时间。鼠标静止停留不会不断触发。
- 点击才起身；睡眠中点击先平滑唤醒再起身。悬停唤醒途中点击可接上起身，后续悬停不会取消点击。
- 拖拽释放只唤醒，不自动起身。眨眼途中点击仍等待眨眼完成。
- 设置页改为固定说明“悬停唤醒 · 点击起身”，旧triggerMode字段保留兼容，不再影响上述规则；其余设置不需要重置。

其余7个片段JSON完全相同，使用的1293张PNG逐项SHA-256与0.2.0发布包一致。当前素材总计1316张PNG、2062帧槽。已经查看全部眨眼中间相位的深浅底联系表，未见明显双瞳、黑块或透明重影。关键帧、帧表和实际闭眼时长检查报告保存在 `artifacts/blink-touchup/report.json`。

Release构建零警告、零错误；75项单元测试通过（核心51、应用24），新增覆盖悬停保持趴坐、点击唤醒后起身、唤醒途中追加点击、拖拽取消待起身，以及两种旧配置均采用新交互规则。未重新控制桌面窗口或修改正在运行的0.2.0程序。

运行新版前先从托盘退出旧版，否则单实例机制会把启动请求送到旧程序。自包含发布目录为 `dist/TablePet-0.2.1-win-x64`。

重建眨眼：`node tools/touchup-blink.cjs`；默认 `npm run assets:prepare` 也会调用补帧步骤。预览为 `assets/strawberry-cat/previews/blink-touchup.gif`（左旧、右新）；`motion-preview.html` 已使用当前帧表。
