# 动作优化验收记录

本文保留0.2.0的完整动作验收。0.2.1按用户最新要求为原眨眼补过渡帧，原关键姿态不变；旧版“眨眼帧表完全不变”的约束不再适用。最新增量检查见 `UPDATE-0.2.1.md` 与 `artifacts/blink-touchup/report.json`，其余动作保持原验收素材。

## 检查范围

本轮保留用户认可的待机眨眼 PNG、顺序和时长，针对撑起、回落、入睡和呼吸进行优化。自然度以姿态、重心、视线和衔接的逐帧检查为主；提高素材采样率、降低像素变化量不能单独证明动作自然。

原版检查基线保存在 `artifacts/motion-qa/baseline/report.json`。基线包含眨眼各帧的 SHA-256、完整清单、透明边界、各片段相邻帧变化和浅深背景联系表。

本轮关键帧使用内置image_gen生成，三个原始透明图表保存在 `assets/strawberry-cat/sources/motion-v2`，切分后的关键帧在 `keyframes-v2`。完整提示词为 [起身提示词](../reference/motion-v2-prompts.json) 与 [蹲下、入睡提示词](../reference/motion-v2-followup-prompts.json)。RIFE4.6只在离线制作时使用，桌宠运行时不调用模型。最终运动PNG保存在 `assets/strawberry-cat/frames/v2`。

## 行为衔接修复

- 眨眼过程中触碰，先完成当前眨眼再开始起身，避免闭眼突然跳成睁眼。多次触碰不重复排队；拖拽或系统暂停会取消等待中的起身。
- 睡眠呼吸可以在任意相位收到唤醒。程序从当前已显示的 PNG 出发，沿呼吸循环的最短路径回到共享睡姿，再播放唤醒。收敛片段最长 240 毫秒，不必等待整轮呼吸。
- 若保持半起身使用动态循环，到期后同样从当前姿态收敛到共享保持姿态，再开始回落。
- 以上收敛片段保留当前 PNG 作为第一帧，保留基准 PNG 作为最后一帧，支持拖拽冻结和恢复，并沿用完成令牌校验。过时的片段回调不能覆盖新动作。
- 入睡中途的唤醒仍只倒放已经显示到的入睡序列，不直接跳到固定睡眠或起身首帧。

这些行为由可控时钟的回归测试检查，不等同于真实桌面操作验收。

## 可重复素材检查

使用项目的 Sharp 依赖或已配置的内置 Node 依赖运行：

```powershell
node tools/qa-motion-assets.cjs assets/strawberry-cat artifacts/motion-qa/current artifacts/motion-qa/baseline/report.json
```

检查器只读取素材，报告生成在指定输出目录。它会验证画布、透明像素、未剪切轮廓、规定连接处的像素一致性，以及被保留眨眼的文件字节与时长。报告还列出相邻帧在可见区域上的预乘 RGBA 差异、脚底范围，并生成每段最多八张采样的联系表。

像素差异用于定位可能跳变的帧，不能据此声称通过主观自然度验收；需要继续查看对应帧、角色大小、眼睑、前爪、头饰和运动方向。插值帧特别需要检查眼睛开合时的重影、边缘融化和尾巴轮廓。

## 第 2 版素材检查结果

对 `manifest` 版本 2 运行上述检查，得到 1296 张独立 PNG、1976 个时间轴帧槽。规定的十处片段连接均使用相同像素，原眨眼文件字节、顺序与时长全部保留。PNG 均为 512 × 512 透明画布，角色轮廓未触碰画布边缘。睡眠呼吸的脚底为 y=477；起身和回落脚底的变化为 y=476–477。

除八帧采样联系表外，还逐张查看以下固定时距的十六帧序列：起身每 50 毫秒、回落每 65 毫秒、入睡每 110 毫秒、完整呼吸每 240 毫秒、呼吸峰值附近每 80 毫秒，以及跨呼吸循环边界每 40 毫秒。另检查了起身睁闭眼和相邻像素变化最大位置的四组实际连续十六帧面部放大图。检查图与 JSON 位于 `artifacts/motion-qa/v2`。

逐帧观察结论：半起身保留短前腿和低重心；撑起时有闭眼再缓慢睁开的过程，最终视线柔和偏侧；回落使用独立动作，避免原先大幅蹲低后重新弹起。入睡有逐渐下压眼睑、低头和放松的过程；呼吸为小幅连续变化，峰值和循环首尾没有明显跳姿。抽查中未发现双瞳、断尾、背景底色或明显透明重影。

在原始像素级放大下，回落帧 38→39、入睡帧 59→60 附近仍能看出生成关键帧之间局部眼型、毛尖线条的细微变化。在 256 像素联系表中不显著，但不应宣称素材每个形状都由人工精修到完全一致。以上是素材逐帧检查，未把静态采样当作实际桌面刷新率或完整实时播放测量。

额外检查图可以重新生成：

```powershell
node tools/qa-motion-sequences.cjs
node tools/qa-motion-hotspots.cjs
```

## 环境边界

本轮未恢复此前用户用 Esc 停止的桌面控制。PNG 解码、状态仿真、静态联系表和逐帧检查均可独立执行；真实桌面交互、实际呈现刷新率、多屏与不同 DPI 环境仍应与已有验收清单分开记录。
