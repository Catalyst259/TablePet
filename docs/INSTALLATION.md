# TablePet 安装与卸载

当前安装包命名为 `TablePet-0.6.0-Setup.exe`，双击后按中文向导安装。安装包包含 Windows x64 程序、.NET 运行时、全部骨骼素材与 12 幅回忆插画，无需开发环境或管理员权限。[0.6.0 历史发布页](https://github.com/Catalyst259/TablePet/releases/tag/v0.6.0-skeletal) 上已发布的文件仍使用旧名 `TablePet.Skeletal-0.6.0-Setup.exe`；当前分支后续构建不再使用这个后缀。

全新安装默认使用 `%LocalAppData%\Programs\TablePet`，在开始菜单创建“TablePet”，可选择创建同名桌面快捷方式。覆盖安装会沿用已登记的当前版本目录；原有 `TablePet.Skeletal` 安装目录无需手工改名。安装完成后可直接启动桌宠。默认不启用开机启动，需要时可在桌宠设置中开启。

更名后保留现有安装身份和配置目录 `%LocalAppData%\DesktopPet.Skeletal`，设置、熟悉度、相伴日与回忆继续使用原记录。它与历史逐帧版分别安装，安装程序会拒绝历史逐帧版所在目录。新旧产品都可能包含 `TablePet.exe`，因此目录保护同时检查历史安装登记和当前骨骼资源及版本身份，不仅按文件名判断。

运行新安装程序并选择已有安装目录即可更新。安装会通知正在运行的当前版本正常保存设置并退出，保留个人配置和已有相伴记录，将程序替换为 `TablePet.exe`，移除本安装目录的旧程序文件，并更新指向本目录的旧快捷方式。已启用且指向同目录旧程序的开机启动项会迁到新文件名，关闭状态不会被开启；其他目录的启动项不受影响。便携包与安装版共享单实例和配置，因此安装时也可能正常退出正在运行的便携版。从 0.5.0 更新后，成长从实际使用开始记录，不补算历史使用；本地预览版已有记录可以继续使用。

从便携包迁入安装版后，使用新的快捷方式启动。如果曾开启便携版开机启动，请在安装版设置中关闭后重新开启，以更新启动路径。

从 Windows“设置 → 应用 → 安装的应用”找到“TablePet”即可卸载。卸载移除本次安装的程序、快捷方式及指向本安装目录的开机启动项，保留个人配置、日志以及其他位置的便携版启动项。重新安装后如需开机启动，请在设置中关闭后重新开启。

仍可使用 ZIP 便携包，完整解压后运行 `TablePet.exe`。
