# 0.2.2 安装和源码备份

## 选择文件

- `TablePet-0.2.2-Setup.exe`：推荐给日常使用者。双击后按中文向导安装，包含运行所需的 .NET 运行时和全部动画素材。
- `TablePet-0.2.2-win-x64.zip`：便携版，解压整个文件夹后运行其中的 `TablePet.exe`。
- `TablePet-0.2.2-source.zip`：本版源码备份，包含源码、动画素材、构建工具脚本及项目文档；供继续开发使用。

本版面向 Windows x64；当前实际运行验证环境是 Windows 11、150% 显示缩放。多屏混合 DPI 和没有开发环境的另一台电脑仍待验收。

## 安装

1. 双击 `TablePet-0.2.2-Setup.exe`。
2. 按向导完成安装。默认装到当前用户的 `%LocalAppData%\Programs\TablePet`，无需管理员权限，也不需要另外安装 .NET 或开发工具。桌面快捷方式默认勾选，可按需取消。
3. 完成页可直接启动桌宠；以后从桌面或开始菜单的“草莓猫桌宠”快捷方式启动。

初次安装不会默认启用开机启动。需要时，在桌宠设置中开启“开机启动”。动画和程序在本地运行，日常使用无需联网。

## 更新与从便携版迁移

运行新版本安装程序，并使用已有安装目录即可更新。点击安装后，安装程序会通知当前桌宠正常保存设置并退出，再复制新文件；如果 10 秒内未退出，会提示手动从托盘退出后重试。安装版和便携版共享单实例，因此正在运行的便携版也会正常退出。

程序同一时间只运行一个实例；如果旧版仍在运行，直接双击另一份 `TablePet.exe` 会打开旧实例的设置。

安装版与便携版共享当前用户的设置文件：`%LocalAppData%\DesktopPet\settings.json`。现有大小、位置、动作间隔等配置会继续使用，无需复制配置文件。

安装完成后使用新的快捷方式启动，避免继续打开旧的便携版。若原先启用了便携版开机启动，可在安装版设置中关闭再重新开启一次，确认开机启动指向新位置。

## 卸载与保留设置

从 Windows“设置 → 应用 → 安装的应用”中找到“草莓猫桌宠”并卸载。桌宠仍在运行时会先询问是否退出。程序文件、安装时创建的快捷方式及指向本安装目录的开机启动项会移除。

卸载保留 `%LocalAppData%\DesktopPet` 中的配置、日志及损坏配置备份，重新安装后可继续沿用。开机启动属于 Windows 注册项，卸载后重新安装时，如仍需开机启动，请在设置中关闭再重新开启一次。若需要完全重置，在退出桌宠后手动备份并删除该目录。

## 校验与源码重建

发布文件旁的 `.sha256` 文件用于检查文件是否在复制或下载过程中损坏。在 PowerShell 中运行 `Get-FileHash -Algorithm SHA256 <文件路径>`，与对应校验文件比较。

源码 ZIP 解压后，按根目录 `README.md` 的“开发和构建”说明操作。运行桌宠不需要 Node.js 或动画模型；只有重建动画素材时才需要它们。

安装包的编译、载荷提取和素材自检，与实际执行 Windows 安装、更新、卸载属于不同验证项目。具体已完成项以发布时的验收记录为准。
