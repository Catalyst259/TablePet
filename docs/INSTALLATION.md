# 骨骼版安装与卸载

在 [0.5.0 骨骼版发布页](https://github.com/Catalyst259/TablePet/releases/tag/v0.5.0-skeletal) 下载 `TablePet.Skeletal-0.5.0-Setup.exe`，双击后按中文向导安装。安装包包含 Windows x64 程序、.NET 运行时与全部运行素材，无需开发环境或管理员权限。

默认安装到 `%LocalAppData%\Programs\TablePet.Skeletal`，在开始菜单创建“草莓猫桌宠 · 骨骼版”，可选择创建桌面快捷方式。安装完成后可直接启动桌宠。默认不启用开机启动，需要时可在桌宠设置中开启。

骨骼版使用独立的安装身份和配置目录 `%LocalAppData%\DesktopPet.Skeletal`，可与原逐帧版分别安装。请勿选择原版 `TablePet.exe` 所在目录；安装程序会拒绝这种目录混用。

运行后续骨骼版安装程序并选择已有安装目录即可更新。安装会通知正在运行的骨骼版正常保存设置并退出，保留个人配置。骨骼版便携包与安装版共享单实例和配置，因此安装时也可能正常退出正在运行的骨骼便携版。

从便携包迁入安装版后，使用新的快捷方式启动。如果曾开启便携版开机启动，请在安装版设置中关闭后重新开启，以更新启动路径。

从 Windows“设置 → 应用 → 安装的应用”找到“草莓猫桌宠 · 骨骼版”即可卸载。卸载移除本次安装的程序、快捷方式及指向本安装目录的开机启动项，保留个人配置、日志以及其他位置的便携版启动项。重新安装后如需开机启动，请在设置中关闭后重新开启。

仍可下载 ZIP 便携包，完整解压后运行 `TablePet.Skeletal.exe`。Setup 和 ZIP 均提供 `.sha256` 校验文件，可用 PowerShell 的 `Get-FileHash -Algorithm SHA256 <文件路径>` 核对。
