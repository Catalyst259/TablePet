# 草莓猫桌宠配置说明

桌宠将当前用户的设置保存到 `%LocalAppData%\DesktopPet\settings.json`。设置窗口提供日常调整入口；动画帧顺序和逐帧时长存放在角色素材的 `manifest.json` 中，两者独立管理。

从0.2.1起，互动固定为“悬停唤醒、点击起身”：悬停会打断入睡或唤醒睡眠，完成后保持趴坐；清醒时悬停只更新互动时间。点击睡眠中的猫会先唤醒再起身。唤醒途中点击同样可以接上起身，重复悬停不会取消点击。旧设置无需重置。

## 配置字段

JSON 字段采用下表中的名称。时间统一以毫秒保存；设置页面的入睡、待机动作、保持与冷却输入使用秒，悬停判定使用毫秒。角色尺寸使用 DIP，随系统 DPI 缩放。0.3.0 的随机待机动作包含眨眼、打哈欠和轻眨单眼；`blinkMinMs` / `blinkMaxMs` 保留旧字段名，控制这三种动作的共同间隔。

| 字段 | 类型 | 默认值 | 约束与作用 |
| --- | --- | --- | --- |
| `schemaVersion` | 整数 | `1` | 当前只支持版本 1。 |
| `autoSleep` | 布尔值 | `true` | 开启无交互自动入睡；关闭后仍可播放待机动作和响应触碰。 |
| `blinkMinMs` | 整数 | `3000` | 待机动作间隔下限，1 至 86,400,000 毫秒。 |
| `blinkMaxMs` | 整数 | `8000` | 待机动作间隔上限，1 至 86,400,000 毫秒，且不小于下限。每次待机动作结束重新抽取间隔。 |
| `sleepAfterMs` | 整数 | `60000` | 无桌宠交互后的入睡期限，1 至 604,800,000 毫秒；其他软件中的键鼠输入不刷新此计时。 |
| `triggerMode` | 字符串 | `"hover"` | 兼容旧配置保留，接受 `"hover"` / `"click"`。0.2.1起不再决定触发方式，两种旧值均采用悬停唤醒、点击起身，设置页不再提供二选一。 |
| `hoverDwellMs` | 整数 | `120` | 实际移入身体后保持命中的时间，1 至 10,000 毫秒。静止停留不重复触发。 |
| `holdMs` | 整数 | `1000` | 半起身保持时间，1 至 60,000 毫秒；静止悬停不延长它。 |
| `cooldownMs` | 整数 | `1000` | 一次反应完成后的冷却时间，0 至 60,000 毫秒；冷却内有效交互仍刷新入睡期限。 |
| `petHeightDip` | 数值 | `240` | 角色画布显示高度，120 至 480 DIP；宽度按素材画布比例计算。必须为有限数值。 |
| `topmost` | 布尔值 | `true` | 使宠物窗口保持置顶。 |
| `clickThrough` | 布尔值 | `false` | 开启后整只猫允许鼠标穿透，触碰和拖拽暂停；可从托盘关闭。默认仅完全透明空白区域交由系统穿透。 |
| `startWithWindows` | 布尔值 | `false` | 由用户在设置页显式开启或关闭当前用户的登录自启动。 |
| `position` | 对象或 `null` | `null` | 保存显示器和工作区内的相对位置；首次启动或显示器不存在时使用可见工作区。 |
| `position.monitorId` | 字符串 | 对象默认 `""` | 显示器设备标识，由应用保存，例如 `\\.\DISPLAY1`。 |
| `position.relativeX` | 数值 | 对象默认 `0.8` | 0 至 1，表示窗口左侧在工作区可移动水平范围中的比例。 |
| `position.relativeY` | 数值 | 对象默认 `0.8` | 0 至 1，表示窗口顶部在工作区可移动垂直范围中的比例。 |

`position` 为 `null` 时不使用对象内部的 `0.8` 默认值，应用会在主显示器可见工作区靠右下的位置首次放置角色。相对位置的可移动范围已经扣除了窗口自身宽高，便于重启或工作区变化后保持完整可见。

完整默认配置示例：

```json
{
  "schemaVersion": 1,
  "autoSleep": true,
  "blinkMinMs": 3000,
  "blinkMaxMs": 8000,
  "sleepAfterMs": 60000,
  "triggerMode": "hover",
  "hoverDwellMs": 120,
  "holdMs": 1000,
  "cooldownMs": 1000,
  "petHeightDip": 240,
  "topmost": true,
  "clickThrough": false,
  "startWithWindows": false,
  "position": null
}
```

## 应用与保存

设置页的当前参数全部通过校验后即时应用。连续调整合并为约 600 毫秒后写盘；拖拽结束保存最终位置，应用退出时再次提交未保存内容。非法参数会显示错误，不会替换正在使用的合法配置。

写盘先在同一目录创建 `settings.json.tmp`，刷新文件后原子替换正式文件。保存失败时保留旧文件，并在设置页或托盘提示失败；当前进程仍可能使用尚未落盘的新值，重启后以最后成功保存的文件为准。

旧配置缺少字段时，缺少项采用默认值。损坏 JSON、非法值或不支持的版本会使应用使用默认设置，并尝试将原文件复制为 `settings.json.invalid-时间戳.bak`。备份失败会记录日志。设置页的“恢复默认”恢复行为、尺寸和开关，同时保留当前窗口位置，并立即保存。

如需手工编辑，先从托盘退出桌宠，再修改 JSON 并重新启动。当前应用不监听外部文件修改；运行中修改文件可能被后续自动保存覆盖。`triggerMode` 使用字符串，不能用数字枚举代替。

## 自启动与托盘开关

自启动通过当前用户注册表项 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 中名为 `TablePet` 的值实现，不需要管理员权限。只有在设置页改变自启动选项时才更新此项；手工修改 JSON 不会自动安装或移除启动项。移动应用文件夹后，如仍需要自启动，应在新位置运行应用并重新关闭、开启该选项。

托盘的“暂停自动动作”和“显示／隐藏”是当前运行会话的控制状态，不写入上述 JSON。暂停自动动作后不再安排新的自动眨眼或入睡，触碰交互仍然可用；隐藏会暂停动画调度。整窗穿透与置顶属于持久化设置。

## 日志

日志位于 `%LocalAppData%\DesktopPet\TablePet.log`，用于记录加载、保存及平台操作异常。单个日志超过约 256 KiB 后轮换为 `TablePet.log.previous`。日志不记录逐帧绘制或持续鼠标移动。
