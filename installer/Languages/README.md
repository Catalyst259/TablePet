# 简体中文语言文件

`ChineseSimplified.isl` 使用 Inno Setup 6.7.3 源码标签中的社区简体中文翻译，适用于 Inno Setup 6.5.0 及之后版本。

- 来源：https://github.com/jrsoftware/issrc/blob/is-6_7_3/Files/Languages/Unofficial/ChineseSimplified.isl
- 上游维护者：Zhenghan Yang（Kira），https://github.com/kira-96/Inno-Setup-Chinese-Simplified-Translation
- Inno Setup 官方翻译索引：https://jrsoftware.org/files/istrans/

保留原始作者说明与 `TranslatorNote`，未修改翻译文字。本项目固定保存该文件，安装包构建时无需联网获取语言文件。
